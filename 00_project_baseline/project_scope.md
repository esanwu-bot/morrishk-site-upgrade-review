## 一、执行摘要

### 1.1 一句话结论

**先把 morrishk.net 做成一个能持续产生询盘的渠道，再谈半导体技术平台。**

具体讲：**产品详情页承接搜索流量，外部链接和社媒带来新增流量，询盘系统完成转化**——这三件事构成第一阶段的主线，其余能力围绕它们展开。

### 1.2 项目优先级（P0 / P1 / P2）

| 优先级 | 工作内容 | 核心目的 | 是否首期交付 |
|---|---|---|:-:|
| **P0** | 产品详情页升级 | 提升产品页的信息质量与询盘转化率 | ✓ |
| **P0** | 外链与社媒引流 | 获取外部流量，导入产品页与询盘入口 | ✓ |
| **P0** | 询盘路径优化 | 让客户更容易提交型号、数量与需求 | ✓ |
| **P1** | 搜索与 SEO | 提升产品页的自然搜索曝光 | ✓（与 P0 并行推进） |
| **P1** | Ds Bit 参数解析 | 提高详情页参数完整度与可信度 | ✓（分批，按重点产品） |
| **P2** | BOM 智能匹配 | 后续增值功能，不阻塞前期上线 | ✗ |
| **P2** | AI Agent、Cross Reference | 待流量与询盘数据积累后再规划 | ✗ |

**这张表的读法**：P0 决定"客户能不能找到我们、敢不敢问我们"；P1 决定"能不能被搜到、参数够不够硬"；P2 是有了客户之后才值得投的增值能力。

**与技术附件《详细技术方案 V1.1》的阶段对应**（两份文档口径一致，只是分法不同）：

| 本方案 | 技术方案 | 说明 |
|---|---|---|
| P0 | Phase 1（获客基础）+ Phase 2 中的引流动作 | 引流先以"人工 + 模板 + UTM"启动，系统化分发器随后接入 |
| P1 | Phase 2（搜索/SEO）+ Phase 3（参数数据能力） | 参数化 B1 跟随详情页上线，全量扩量由数据决定 |
| P2 | Phase 4（智能化与扩展） | 单独立项，不占首期资源 |

### 1.3 为什么这样排

老站已经有 **1,009 万个产品详情页**、982 个分类、1,427 个品牌、56.8 万份去重 PDF。这些资产的问题不是"没有"，而是"没有被用好"：

- 详情页内容薄、同质化，谷歌收不进，客户看一眼就走；
- 站外几乎没有可被引用的资产，流量来源单一，只能等自然搜索；
- 询盘链路存在，但没有被当作一个"产品"来设计，也没有被度量。

所以第一阶段不需要新平台，需要**把已有的千万级资产重新组织成"能被搜到、能被相信、能直接下单询问"的形态**。这三件事做完，才谈得上 BOM 与 Agent。

### 1.4 为什么不重写老站

| 重写的诱惑 | 现实代价 |
|---|---|
| 新框架、新界面、看起来更现代 | 约 **1009 万个产品详情页**已运行多年，换 URL 就要全量 301，排名与流量存在不可控的下滑 |
| 开发可能更快 | 后台、询价、发信、80 个语种入口都要重做，周期与预算远高于原地升级 |
| 技术栈更新 | 数据是 2024-11-30 的静态终态，不需要新框架的写入能力，重写带不来对等收益 |

**结论：原地升级，URL 不动，数据不动，能力逐块替换。**

### 1.5 第一阶段要交付的三件事

| 环节 | 客户能感知到什么 | 衡量方式 |
|---|---|---|
| **① 产品详情页** | 打开任意重点型号，能看到完整参数、Datasheet、相关型号，询价按钮一眼可见 | 产品页访问量、页均停留、详情页→询价点击率 |
| **② 外部引流** | LinkedIn / Reddit / YouTube / 行业目录上开始出现 morrishk 的内容，且每条都能追踪 | 各渠道带来的会话数与询盘数 |
| **③ 询盘转化** | 客户可以单型号询价、多型号批量询价、上传 BOM，提交后有明确回执 | 询盘提交数、有效询盘数、响应时长 |

### 1.6 收益预期（预估，非承诺）

按"离询盘的距离"分两类看，避免把慢变量混进快变量里。

**A 类：直接影响询盘（P0，3–6 个月可见）**

| 杠杆 | 作用机制 | 观察口径 |
|---|---|---|
| 详情页重构 | 参数、资料、相关型号齐全，客户不必跳走 | 详情页→询价点击率、页均停留 |
| 询盘路径简化 | 少填字段、支持多型号与 BOM 上传 | 询盘提交数、表单放弃率 |
| 社媒 + 视频引流 | 站外带来新会话，落到产品页 | 渠道会话数、渠道询盘数 |
| 行业目录与外链 | 带来精准参考流量与品牌可信度 | 引荐流量、引荐询盘数 |

**B 类：放大上限（P1，6–12 个月起复利）**

| 杠杆 | 作用机制 | 观察口径 |
|---|---|---|
| 搜索容错与分面 | 错字、中缀、带空格都能命中 | 挽回约 **20%–30%** 的搜索流失（行业经验区间，以搜索日志为基线校准） |
| 结构化数据 | 谷歌结果可展示参数、库存、询价 | 富结果点击率、收录量 |
| 参数化覆盖 | 重点产品页内容变厚，长尾词可承载 | 参数覆盖率、被收录页数 |
| 五语种 SEO | hreflang + 本地化内容 | 新增语种市场曝光 |

**说明**：以上为方向性预估，用于判断投入优先级，不构成效果承诺。项目启动后先建立基线，再按真实数据校准。
