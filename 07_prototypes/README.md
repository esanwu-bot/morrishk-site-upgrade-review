本目录是 morrishk.net 升级项目的**新版原型**，用于原型设计评审。
方案文档通过不等于原型实现符合方案，因此原型单独送审，判定口径与文档评审分开。

- 入口：**`index.html`**（按真实用户路径串联四个原型，建议从这里开始）
- 版本：`v1.5.1-prototype` · 2026-11-16（v1.5 的小修订，不推翻设计系统）
- 依赖：零外部依赖，纯本地 CSS / JS，可离线打开
- 本轮主题：**库存状态语义统一 + 审计证据补齐**（Design System 主体沿用 v1.5）

历史上存在两份设计文档且**存在冲突**。本轮起不再由页面自行裁定，统一收口到
**`07_prototypes/DESIGN.md` v1.0**：

| 文档 | 效力 |
|---|---|
| **`07_prototypes/DESIGN.md`** v1.0 | **唯一视觉权威**。本文生效后，其余文档的视觉条款一律废止 |
| `prototype/design.md` v1.0 | **仅保留交互与信息密度**效力（参数化检索、高密度列表、替代料逻辑、空状态）。其品牌蓝 `#0052CC` 与彩色语义徽章条款**废止** |
| 旧 `stitch_.../DESIGN.md` | 已并入 `07_prototypes/DESIGN.md`，不再单独引用 |

### 3.2 实现层（本轮新增）

```
assets/tokens.css   192 条声明 / 188 个唯一 Token，三层架构：
                      Primitive（--red-600 / --gray-200 …）仅内部组合
                    → Semantic（--color-brand / --color-border …）业务代码只用这一层
                    → Component（--btn-h-md / --table-row-h …）组件样式引用
        ↓
assets/proto.css    17 个分区，零字面色值，全部 var(--*)
        ↓
*.html              页面不写任何色值，行内样式仅保留布局微调
```

### 3.3 关键取值

| 项 | Token | 值 |
|---|---|---|
| 主色 | `--color-brand` | `#DC2626` |
| 画布 / 表面 | `--color-canvas` / `--color-surface` | `#F8FAFC` / `#FFFFFF` |
| 描边 | `--color-border` | `#E2E8F0` |
| 文字 | `--color-text` / `--color-text-muted` | `#0F172A` / `#64748B` |
| 圆角 | `--radius-xs` / `-sm` / `-md` | 2px / 4px / 6px（禁止 pill） |
| 字体 | `--font-feature` | `'tnum' 1, 'cv05' 1, 'zero' 1` |
| 表格 | `--table-head-h` / `--table-row-h` | 32px / 36px |
| 阴影 | `--shadow-none` | 数据面零阴影，仅浮层有阴影 |

完整 Token 表见 `DESIGN.md` 第三节。

### 3.4 本轮迁移口径

**结构与交互零改动，视觉取值有 51 条变更**（v1.5 曾声称"只改取值来源"，实测不成立，v1.5.1 已更正）：

| 项目 | v1.4 | v1.5.1 |
|---|---|---|
| 色值来源 | 各页面 / `proto.css` 内字面写死 | 全部走 `assets/tokens.css` |
| 变量命名 | `--primary` / `--surface` / `--text` | `--color-brand` / `--color-surface` / `--color-text` |
| 行内圆角 | `border-radius:4px`（10 处） | `var(--radius-sm)` |
| 间距 / 字号 / 阴影 / 层级 | 手工零值（9px、10px、14px、7px…） | 吸附 4pt 与 Token 刻度（8px、12px、16px、6px…），**51 条取值变更** |
| 库存状态 | 色点 + 数量；低库存用红色徽章 | 颜色 + 图标 + 文字三通道；低库存用琥珀，缺货/EOL 用红 |
| 页面结构 / 信息架构 / 交互路径 | — | **零改动** |
| `data-mock` 标注 | 109 处 | **109 处（零改动）** |

**像素差分实测**：同视口逐像素差异 3.11% – 25.59%（严格口径），合计 11.64%；
按每页最佳纵向偏移补偿后合计 **9.62%**，即"整体错位"只解释约 2 个百分点。
原因是间距吸附导致的累计纵向位移（详情页底部达 +30px）叠加库存组件替换，**不是抗锯齿噪声**。
逐页数据见 `VISUAL_DIFF.md` 第三节，逐条取值变更见 `reference/prototype_shots/CSS_VALUE_DIFF.md`。

## 五、原型标注系统

Reviewer 要求检查「HTML 中的假数据、占位链接、伪提交按钮是否被明确标注」。
本原型用**可切换的标注层**回答，而不是只在文档里口头声明。

**用法**：点右下角「原型标注」按钮，或按 `?` 键。

- 所有 mock 元素带 `data-mock="说明"` 属性；
- 开启后显示**琥珀色虚线框**与说明标签；
- 按钮上的数字即当前页 mock 元素数量；
- 每个页面底部有**原型状态条**，分四行：对应方案 / 实施阶段 / 已实现 / 模拟 / 待开发 / 本轮修改。

标注分布：`home` 28 处、`product_detail` 33 处、`search` 32 处、`inquiry` 16 处，**合计 109 处**。

标注分三级：

| 标记 | 含义 |
|---|---|
| 已实现 | 交互可点、状态可切，接近真实行为 |
| 模拟 | 假数据、占位链接、伪提交，不可当真 |
| 待开发 | 本期不做或需后端配合 |

## 八、判定边界建议

| 判定 | 适用 |
|---|---|
| `PASS` / `PARTIAL` / `FAIL` | 信息架构、视觉体系、交互路径、表单规则、状态表达、**Design System 一致性** |
| `NOT VERIFIABLE` | 前端代码质量、接口契约、性能、安全、权限、SEO 实际输出、真实数据下的表现、**多浏览器兼容性** |

视觉通过不代表前端代码、接口、性能与安全通过，四者分开判定。

**本轮特别说明**：`TOKEN_AUDIT.md` 的 5/5 通过是**源码层面的机械检查**，
证明"没有字面色值、没有未定义变量、没有越界圆角"，**不等于**设计体系在视觉上已通过评审。
视觉是否统一仍需 Reviewer 目视判定。
