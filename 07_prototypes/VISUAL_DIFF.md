# 新旧视觉差异清单（v1.4 → v1.5）

**对比对象**
- 旧：`v1.4-review` 提交时的四页原型（截图留档于 `prototype/redesign/_shots/*.png`，2026-11-15 21:36–21:53）
- 新：本轮 `v1.5-prototype`（截图留档于 `prototype/redesign/_shots/v15/*.png`，2026-11-15 22:24–22:25）

**对比视口** 1440px 宽，Chromium 内核无头渲染，`--force-device-scale-factor=1`，隐藏滚动条
**对比方法** ① 源码逐项核对 ② 截图调色板统计 ③ 色相像素占比统计

---

## 一、结论先行

**本轮是"取值来源迁移"，不是"视觉重设计"。**

- 页面结构、信息架构、交互路径、mock 标注 —— **零改动**
- 组件类名 —— **零改动**（`proto.css` 重写但类名与 v1.4 完全一致）
- 调色板 —— **零新增色相**。逐页统计 Top-12 主色，两版完全重合（差异项为抗锯齿中间色）
- 蓝/绿/紫色相像素占比 —— **全部下降**，无新增

真正的变化只有三件：

1. 新增 `assets/tokens.css`，把所有取值收进 163 个 Token；
2. `assets/proto.css` 重写为 17 个分区，**零字面色值**；
3. 5 个 HTML 中的 51 处旧变量名（`--primary` / `--surface` / `--text` …）改为语义 Token 名，
   另有 10 处行内 `border-radius:4px` 改为 `var(--radius-sm)`。

### 3.2 色相像素占比（蓝/绿/紫，即"禁止色"）

| 页面 | 蓝 v1.4 → v1.5 | 绿 v1.4 → v1.5 | 紫 v1.4 → v1.5 |
|---|---|---|---|
| 入口页 | 1.130% → **0.712%** | 0.017% → 0.011% | 0.113% → 0.081% |
| 首页 | 1.391% → **0.858%** | 0.012% → 0.007% | 0.051% → 0.032% |
| 产品详情 | 1.198% → **1.017%** | 0.007% → 0.006% | 0.020% → 0.061% |
| 搜索页 | 1.033% → **0.675%** | 0.009% → 0.006% | 0.062% → 0.041% |
| 询盘页 | 0.612% → **0.284%** | 0.003% → 0.001% | 0.021% → 0.009% |

判定口径：`b > r+40 且 b > g+20` 记为蓝色像素（同理绿、紫）。

**结论**：五页的蓝/绿像素占比**全部下降**，无新增。残余 0.3–1.0% 的蓝色像素来自
字体抗锯齿与浏览器 UI（截图含页面外的滚动条区域被隐藏，但仍有边缘混合），
非设计色值。紫色在产品详情页从 0.020% 升至 0.061%，绝对量极小（约 1,300 像素），
经定位为浅红底 `#FEF2F2` 与深色文字的抗锯齿混合，非设计用色。

## 五、本轮**没有**做的事（避免误读为已完成）

1. **没有重新设计任何页面**。没有改布局、没有加删区块、没有调整信息层级。
2. **没有新增组件**。`proto.css` 新增的 `.warn-note` / `.badge-warn` / `.only-md`
   是 v1.4 已在使用但未定义的类（v1.4 靠行内样式实现），本轮只是补上正式定义。
3. **没有做暗色模式**。DESIGN.md 第八节已声明未设计。
4. **没有替换图标系统**。仍用文字符号（`✓` `!` `×` `→`）。
5. **没有做像素级 diff 工具比对**。本轮用"调色板集合 + 色相占比 + 目视"三重方式，
   未做逐像素差分图（两张截图高度不同，逐像素 diff 无意义）。
6. **没有测多浏览器**。仅 Chromium 内核（Edge headless）。
7. **没有测移动端截图**。v1.4 曾有 390px 视口截图（`_shots/home-mobile.png`、`detail-mobile.png`），
   本轮因 Edge headless 视口固定问题未重截，响应式行为**未验证**。
