# 视觉迁移差异评估（v1.4 → v1.5.1）

> **本文不主张"像素完全一致"。** 上一版（v1.5）用调色板统计与人工目视得出"八个主色一一对应、
> 色值完全相同"的结论，该结论**不成立**——它只覆盖了主色，没有覆盖间距、字号、阴影、层级，
> 也没有做过逐像素差分。本轮改为给出**实测数字 + 逐条取值清单 + 差异原因**。

## 一、结论（先说结果）

1. **Token 化迁移已完成**：`tokens.css` 之外的样式声明中，字面色值为 **0**（见 `TOKEN_AUDIT.md` 第 A 节）。
2. **色相方向未变**：仍是 crimson + 中性灰阶 + 功能琥珀，未引入蓝 / 绿 / 紫。
3. **视觉并非像素一致**：同视口逐像素差分实测差异 **3.11% – 25.59%**（可见差异 2.99% – 15.15%）。
   在**整页单一纵向位移模型**下补偿后，合计从 **11.64% 降至 9.62%**——说明全局纵向平移
   不足以解释大部分像素差异；剩余差异同时含内容变化与未被该模型解释的布局差异，
   **不等同于纯内容差异**（见第三节两个口径并列与 `prototype_shots/pixel_diff/PIXEL_DIFF.md` 1.1 明细）。
4. 差异有三类**已定位**的来源，全部可解释、可逐条核对：

   | 来源 | 数量 | 性质 |
   |---|---|---|
   | 间距 / 字号 / 圆角 / 阴影 / 层级吸附到 4pt 与 Token 刻度 | 42 条取值变更 | **有意为之**，属设计系统统一 |
   | 库存状态组件替换（有货加 `✓` + 文字，可用量表少一行） | 16 处 | **有意为之**，本轮整改项 |
   | 入口页设计体系说明文字改写 | 1 处 | **有意为之**，文字内容变更 |

5. **不能从本文推出**"设计已通过"或"视觉无回归"。本文只回答"改了什么、差多少、为什么"。

**前置校验是硬性条件，不是提示。** 差分脚本在输出任何数字之前检查三件事，任一不满足即非零退出、
**不写报告、不留半成品差异图**：两版页面集合必须完全相等（缺页/多页都不允许静默跳过）、
每页尺寸必须相同、完成页数必须等于页面集合页数。本轮的实测结果是 5 = 5、全部 1440×2600、5/5 完成，
详见 `reference/prototype_shots/pixel_diff/PIXEL_DIFF.md` 第 0 节。

## 三、像素差分实测

| 页面 | 尺寸 | 严格差异像素 | 占比 | 可见差异像素 | 占比 | 差异行段数 | 补偿后占比 | 最佳 dy |
|---|---|---|---|---|---|---|---|---|
| `index.html` | 1440×2600 | 709,741 | 18.957% | 371,013 | 9.910% | 34 | 18.957% | +0 px |
| `home/index.html` | 1440×2600 | 188,715 | 5.040% | 146,551 | 3.914% | 37 | 5.040% | +0 px |
| `product_detail/index.html` | 1440×2600 | 958,099 | 25.590% | 567,145 | 15.148% | 65 | **15.550%** | **+25 px** |
| `search/index.html` | 1440×2600 | 206,302 | 5.510% | 133,321 | 3.561% | 28 | 5.510% | +0 px |
| `inquiry/index.html` | 1440×2600 | 116,590 | 3.114% | 111,976 | 2.991% | 37 | 3.114% | +0 px |
| **合计** | 5 × 3,744,000 | 2,179,447 | 11.641% | 1,330,006 | 7.105% | — | **9.623%** | — |

两个口径回答两个不同问题，缺一都会误判：

- **严格口径 11.64%**：把"内容整体上下错位"也算成差异。回答"两版看起来是不是一模一样"。
- **位移补偿口径 9.62%**：允许每页整体平移一个最佳 dy 后再比。回答"扣掉整体错位，还剩多少真的不一样"。

补偿后仍剩 9.62%，说明这 11.64% **不能被整体归因于页面平移**——全局纵向平移只消掉约 2 个百分点。
需要说明的是，剩余 9.62% 是**当前受限补偿模型下的残余差异率**：模型只搜纵向、只允许整页单一 dy，
分段位移、横向位移、局部重排都未建模，因此它既包含真实的内容变化，也包含模型没解释掉的布局差异，
**不能直接当作纯内容差异**。反过来说，只有**详情页**存在能被单一 dy 抵消的全局位移
（+25px，25.59% → 15.55%）；其余四页 dy 均为 0，他们的差异本来就分散在局部，不是整体错位。

**这不是抗锯齿噪声。** 若差异仅来自文字抗锯齿，差异像素应集中在字形边缘、占比通常 < 1%。
实测 3.11% – 25.59%，且差异呈**整段连续色带**（详情页有 65 个差异行段）；
位移补偿后仍余 9.62%，进一步排除了"只是整体挪了几像素"这一种解释。

## 四、累计纵向位移（关键证据）

间距从 v1.4 的"手工零值"（9px / 10px / 14px / 7px）吸附到 4pt 刻度（8px / 12px / 16px / 6px）后，
每张卡片、每个表头都矮或高几像素，**误差沿页面累加**，导致下半页内容与旧版不再逐行对齐。

在同一坐标系下测得的局部纵向偏移（正数 = 新版内容更靠上）：

| 页面 | y≈200 | y≈900 | y≈1600 | y≈2200 |
|---|---|---|---|---|
| `product_detail` | 0 px | +21 px | +24 px | **+30 px** |
| `home` | 0 px | +4 px | +4 px | +4 px |
| `search` | 0 px | +14 px | （该区域为空白，无有效对齐） | — |

这解释了为什么"顶部几乎看不出差别、越往下差异越大"。

脚本另做了一次**全局**纵向偏移搜索（±40px 内取差异率最小的单一 dy），结果与上表的局部测量互相印证：

| 页面 | 人工局部测量 | 脚本全局最优 dy | 说明 |
|---|---|---|---|
| `product_detail` | 0 → +30 px（自上而下递增） | **+25 px** | 单一 dy 只能折中：整页平移 25px 时，上半页反而被推离，故最优值落在区间中段 |
| `home` | 0 → +4 px | **0 px** | 位移仅 4px，整页平移的收益小于上半页因之产生的损失 |
| `search` | 0 → +14 px | **0 px** | 同上 |

**这说明位移是分段的，不是整页统一偏移**。所以补偿口径（单一 dy）只能部分抵消，
补偿后仍有 9.62% 属于预期——不能反过来把残余差异全算到"没补偿干净"头上。
要真正按分段位移比较，需要逐段估计 dy，本轮未做，列为后续可改进项。

## 五、取值变更逐条清单

完整清单见 `reference/prototype_shots/CSS_VALUE_DIFF.md`（由脚本生成，可重跑）。
统计口径：两版 `proto.css` 在共同选择器下共 703 条声明，其中 **652 条取值等价**
（仅书写差异，如 `#fff` → `#ffffff`、`var(--primary)` → `var(--color-brand)`），
**51 条真实变更**：

| 类别 | 条数 | 典型变更 | 判断 |
|---|---|---|---|

| 颜色 | 9 | `.errmsg` / `.is-error` `#dc2626`→`#991b1b`（danger 用 red-800，对比更强）；`body.annot` 虚线 `#f59e0b`→`#b45309` | 有意（对比度提升） |
| 排版 | 8 | `.logo .sub` 字距 `.12em`→`.04em`；`.btn` / `.mainnav a` 字距 `.01em`→`0`；提示条行高 `17px`→`18px` | 吸附 Token 刻度，有意 |

| 层级 | 4 | `.pop` `60`→`40`；`.bulkbar` `80`→`60`；`.facet-drawer` `100`→`80`；`table.grid th` `2`→`10` | 归入 `--z-*` 体系，有意 |
| 动效 | 2 | `.12s` / `.16s` → `120ms` / `180ms` + `cubic-bezier` | 统一缓动，有意 |

## 七、本文未覆盖的事项（必须一并阅读）

1. **只覆盖一个内核**：Chromium（Edge headless）。Firefox / Safari 未测。
2. **只覆盖一个视口**：1440×2600。窄屏、平板、真机均未测，移动端**未重新截图**。
3. **只覆盖首屏 2600px**：页面更长时超出部分不在差分范围内。
4. **不含交互态**：hover / focus / 展开替代料 / 打开浮层等状态未截图。
5. **字体渲染依赖本机**：换机器或换字体版本会产生系统性差异，本文结论**仅在相同环境下可复现**。
6. **差异为 0 也不等于视觉正确**：只证明两版渲染一致，不证明设计合理。
7. **未做对比度工具化扫描**：颜色变更的对比度影响为人工估算。
8. **位移补偿只搜纵向、且只搜整页单一 dy**：不做横向偏移、不做分段位移。累计位移是分段的，
   单一 dy 只能折中，因此 9.62% 里仍含未被抵消的位移成分。若允许更灵活的对齐方式
   （分段 dy、横向偏移），最小像素差异理论上不会高于 9.62%——在这个前提下它可以称为
   **受限模型下残余差异率的上界**；但它不是内容差异的精确值，也不能反过来说是内容差异的下界。

## 八、给 reviewer 的判断依据

三个口径并列，请按需取用，不要只引其中一个：

| 口径 | 数字 | 回答的问题 |
|---|---|---|
| 严格逐像素 | **11.64%** | 两版看起来是否一模一样 |
| 位移补偿（±40px 整页单一 dy） | **9.62%** | 在受限对齐模型下残余多少；含未被该模型解释的布局差异 |
| 取值变更条数 | **51 条**（其中 42 条为刻度吸附，9 条为配色调整） | 到底改了什么、能不能逐条核对 |

如果评审标准是"**视觉必须与 v1.4 逐像素一致**"——**本轮不通过**，实测 11.64%（严格口径）。
如果评审标准是"**视觉体系成立、差异可解释、无未记录变更**"——本文提供了逐条清单与实测数字，
请据此判断这 51 条取值变更是否可接受。

**需要 reviewer 单独裁定的是"间距吸附"这一类的接受标准**，而不是笼统的 11.64%。
它在 51 条里占 21 条（最大一类），也是像素差异的主要来源。可裁定的问法是：

- 单条间距变化是否都在 **±4px 内**、且方向统一朝 4pt 刻度？（本次是）
- 变化是否**未改变信息层级、未造成换行/截断/重叠**？（本次目视为是，附差异图可复核）
- 是否接受由此产生的**累计位移**（详情页约 30px）？（这是唯一有实质观感影响的部分）

若对第三点的答案是"不接受"，则不是修脚本能解决的，需要改为逐段补偿渲染或回退零散取值。

乙方立场：这 51 条变更是**设计系统统一必然的副作用**（把手工零值吸附到 4pt 与 Token 刻度），
不是无意的回归。若 reviewer 要求视觉零差异，需要回退到 v1.4 的零散取值，
那等于放弃 Token 刻度——两者不可兼得，需要 reviewer 明确取舍。
