## 二、为什么第 3、5 张不可用（技术说明）

### 2.1 产品详情页（第 3 张）

主站是 Nuxt 应用（`static.lcsc.com/feassets/pc/nuxt/*`），但产品详情页是**另一个 Next.js 应用**
（`static.lcsc.com/item/_next/static/css/*`）。两者样式体系不同，且 Next.js 的组件级 CSS
通过 JS 按需注入——剥离 `<script>` 后，这些 CSS 永远不会被加载。

结果：HTML 结构与文本都在，但样式缺失，页面呈无样式状态。截图**仅作采集留痕**，
不用于任何视觉结论。该页的信息架构改由页面内嵌的 `__NEXT_DATA__` JSON 字段清单还原，
见 `lcsc_research.md` 第三节。

### 2.2 报价状态页（第 5 张）

`/order` 与 `/quote` 均返回 HTTP 302 跳转登录。LCSC 的报价单强制登录后可见。
唯一可确认的事实是 BOM 页存在 `Quotes` 页签（复数形式，说明是列表形态）。

**没有截图，也没有做任何推测性描述。**
