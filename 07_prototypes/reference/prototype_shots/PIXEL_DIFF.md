## 0. 前置校验（硬性条件）

脚本在生成任何数字之前先做三项校验，任一不通过即非零退出且**不写报告**，不存在「少比一页仍然 PASS」的情况。

| 校验项 | 规则 | 结果 |
|---|---|---|
| 页面集合一致 | 两目录 PNG 文件名集合必须完全相等 | **PASS**（5 = 5） |
| 尺寸一致 | 每页两图尺寸必须完全相同，不做缩放对齐 | **PASS**（全部 1440×2600） |
| 差分完成度 | 完成页数必须等于页面集合页数 | **PASS**（5 / 5） |

**失败与发布语义**：全部页面差分完成、报告写毕、产物校验通过后才整组发布。发布用同一文件系统内的**目录级原子重命名**，目标 `diff/` 必须预先不存在；已存在时默认拒绝（退出 6），加 `--replace-dir` 才替换，且旧目录在发布成功后才删除。报告中转是提交点：报告替换失败则连同新目录一起回滚。**任何失败都不触碰历史证据。**

**合计（严格口径）**：2,179,447 / 18,720,000 像素（11.642%），可见差异 1,330,006（7.105%）。

**合计（位移补偿口径）**：按每页各自的最佳 dy 平移后，差异 1,797,945 / 18,684,000 像素（9.623%）。

### 1.1 位移补偿明细（可逐页核对分子分母）

| 页面 | 最佳 dy | 平移后差异像素 | 重叠面积 | 残余差异率 |
|---|---|---|---|---|
| `detail` | +25 px | 576,597 | 3,708,000 | 15.550% |
| `home` | +0 px | 188,715 | 3,744,000 | 5.040% |
| `index` | +0 px | 709,741 | 3,744,000 | 18.957% |
| `inquiry` | +0 px | 116,590 | 3,744,000 | 3.114% |
| `search` | +0 px | 206,302 | 3,744,000 | 5.510% |
| **合计** | — | **1,797,945** | **18,684,000** | **9.623%** |

**校验式**：1,797,945 / 18,684,000 = 0.09623 = 9.623%，与上表合计一致。

**分母为何与严格口径不同**：严格口径分母是原图总面积（18,720,000），补偿口径分母是各页**平移后的重叠面积**之和（18,684,000）。dy≠0 的页面上下各裁掉 |dy| 行，重叠面积随之减少，两个分母不可混用、也不互相替代。

**这个数字能说明什么、不能说明什么**：在当前测试的**整页单一纵向位移模型**下，差异率由 11.642% 降至约 9.623%——说明全局纵向平移不足以解释大部分像素差异。但剩余差异同时包含「内容变化」与「未被本模型解释的布局差异」（分段位移、横向位移、局部重排都未建模），**不能直接等同于纯内容差异**。

## 3. 口径限制（必须一并阅读）

1. **只覆盖一个内核**：Chromium（Edge headless）。Firefox / Safari / 移动端未测。
2. **只覆盖一个视口**：1440×2600。窄屏、平板、真机均未测。
3. **只覆盖首屏 2600px**：页面更长时超出部分不在差分范围内。
4. **不含交互态**：hover / focus / 展开替代料 / 打开浮层等状态未截图。
5. **字体渲染依赖本机**：换机器或换字体版本会产生系统性抗锯齿差异，本报告结论**仅在相同环境下可复现**。
6. **差异为 0 不等于视觉正确**：只证明两版渲染一致，不证明设计合理。
7. **位移补偿只搜纵向、只搜全局单一偏移**：不做横向偏移、不做分段位移。页面不同区段位移量不同时（累计位移的典型表现），单一 dy 只能部分抵消，补偿后残余仍偏大属于预期。
8. **补偿口径不做内容语义判断**：它只回答「在这个受限的对齐模型下残余多少」，不判断剩下的差异是否可接受，也不能把残余率直接当作纯内容差异。
