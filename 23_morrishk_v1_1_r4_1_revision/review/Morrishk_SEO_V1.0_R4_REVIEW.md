# 1. 项目目标及业务指标

SEO 首期目标服务于项目总目标：通过技术 SEO、重点产品页面、内容与询盘链路优化，提高目标市场的有效采购询盘获取能力。SEO 不以“保证排名第一”或“保证询盘数量”为交付条件。

| --- | --- | --- | --- |

| 自然搜索访问 | 非付费搜索来源会话 | GA4 + GSC | 业务观察 |

# 7. 页面 SEO 规范

页面级 SEO 元素沿用《Morrishk SEO Elements and Page Spec V1.0.xlsx》的 11 类页面 × 28 项规范，本附件不重复 308 行明细。核心规则如下：

| 页面类型 | 索引 | Canonical | 结构化数据 | 关键约束 |
| --- | --- | --- | --- | --- |
| HOME | 是 | 自指 | Organization/WebSite | 只输出一次实体；首页唯一 |
| PLP | 是 | 自指 | CollectionPage/ItemList/Breadcrumb | 分页/筛选按规则 |
| CATEGORY | 是 | 自指 | CollectionPage/ItemList/Breadcrumb | 分类映射不自动改 URL |
| PDP | 条件 | 自指 | Product/Breadcrumb；Offer 仅真实价格 | RELEASE_APPROVED；Tier A/B 进 Sitemap |
| SEARCH | 否 | 自指 | 不适用 | noindex,follow；不进入 Sitemap |
| BRAND | 是 | 自指 | CollectionPage/ItemList/Breadcrumb | 品牌/供应商语义待确认 |
| INQUIRY | 否 | 自指 | 不适用 | 表单/成功页 noindex |
| BLOG LIST/ARTICLE | 是 | 自指 | CollectionPage / Article | 标签页按内容量决定索引 |
| STATIC | 是（低价值可 noindex） | 自指 | WebPage/About/ContactPage | 未知 slug 必须 404 |

Hreflang 仅在真实翻译页面之间输出；第一阶段仅 en，不输出虚假 hreflang。Canonical 与 noindex 不组合指向他页。

# 8. 旧域名及 URL 迁移方案

迁移先盘点、后映射、再验证。未取得旧 URL 数据前，不声称映射完成；不承诺迁移后排名、收录或流量不下降。对应交付编号：SD-04 / FR-3-042。

URL 回归规模不再固定条数：旧 URL 全量盘点；首页、主要分类/品牌、重点产品、主要落地页、历史高流量 URL、已有外链 URL 和所有计划 301 的源 URL 做 100% 关键核验；其余按旧 URL 总量分层抽样（建议规则：≤1,000 全量；1,001–10,000 ≥30%；10,001–100,000 ≥5,000；>100,000 ≥10,000 + 分层），样本量待负责人/客户确认。

Hreflang：第一阶段仅 en，不输出任何 hreflang（包括 x-default）；第二语言真实发布后，才建立互指并设 x-default=en。

| 环节 | 要求 | 交付/验收 |
