# 05 剩余风险

## 1. 本轮未解决

| 编号 | 风险 | 影响 | 建议 |
|---|---|---|---|
| R-01 | 后台首页 `/ejadmin-index.html` 在登录后返回 **500**：`SQLSTATE 1055`，`ORDER BY snsii_nav.id` 不在 `GROUP BY` 中（`ONLY_FULL_GROUP_BY`） | 后台导航页不可用；不影响登录本身与下载授权 | 新增缺陷 F-13，Round 40 修复：为查询补聚合或调整 `GROUP BY`/`ORDER BY` |
| R-02 | `yii2 2.0.53` 受 CVE-2026-39850 影响，修复版 2.0.55 **未发布** | 视图名冲突导致 LFI（当前视图名固定，暂无利用路径） | 监控 2.0.55 发布后升级 |
| R-03 | `yii2-redis 2.0.17` 受 CVE-2025-48493 影响，修复版 2.0.20 **未发布** | 连接失败时日志可能泄露 AUTH | 当前未启用 Redis；启用前必须升级 |
| R-04 | `phpspreadsheet 1.19.0` 31 条通告（含 critical SSRF/RCE） | 当前无解析调用；但 `xls/xlsx` 在上传白名单内 | 若增加导入/预览，先升级到 ≥1.30.7 并加隔离 |
| R-05 | `guzzle 7.4.1` 14 条通告（含 high） | 经 google/apiclient 使用 | 与 apiclient 一同升级评估 |
| R-06 | authKey 由密码哈希派生 | 密码哈希泄露者可伪造持久登录票据（与直接存 `auth_key` 的风险同级） | 后续可新增独立 `AuthKey` 列并做迁移 |
| R-07 | 生产 Nginx 配置未验证 | 无法确认生产路径保护/上传限制 | 用生产配置副本复测 |
| R-08 | MySQL 5.6→8.4 真实迁移、引擎/字符集转换未演练 | 生产迁移风险未量化 | 独立迁移演练 |

## 2. 已验证可接受（本轮）

- 登录成功/失败、会话保持、登出、角色隔离；
- 下载授权 13 项矩阵全部符合预期；
- 独立测试 Nginx 下敏感路径 404/403，正常页面与下载接口正常。

## 3. 未覆盖

- 生产部署、生产数据库变更、真实 SMTP、第三方 API；
- 并发/压测、备份恢复演练；
- 后台其余页面（除导航页 500 外）未逐页回归。

## 4. 边界

本轮不构成 Morrishk V1 功能验收或生产验收；未标记任何 READY / ACCEPTED / RELEASE 状态。
