## 3. 证据如何产生

- **正文/表格读回**：python-docx 按 `w:body` 子元素顺序遍历 `w:p` / `w:tbl`；页眉页脚同时导出段落与域指令（`PAGE` / `NUMPAGES`）。表格逐行逐格导出，未使用构建脚本断言。
- **工作簿读取**：openpyxl 直接读取 04 XLSX 与 90 矩阵的全部工作表，输出实际表头、数据行、公式、合并、冻结、筛选、页面设置。
- **页面渲染**：Word COM 只读打开 DOCX，使用 `Microsoft Print to PDF` 打印为内部 PDF；PyMuPDF 以 100 DPI 栅格化全部 59 页，并提取文本块、字体列表、页码、页眉页脚、文本/图形 bbox。
- **分页问题判定**：逐页检查“重复表头之后的第一段内容是否为完整编号行”，并对问题页做人工目视。
- **映射核验**：直接比较 90 矩阵、02 DOCX 附录 A/新增表、04 XLSX 08/09 的编号集合。

内部 PDF **不在本目录**，也未作为客户交付物提交；仅 PNG 作为 Reviewer 预览。
