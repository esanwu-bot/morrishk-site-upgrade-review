# 04 · P0 协调升级的求解试验（dry-run，未落地）

- 目的：验证"P0 改完后 8.4 能否求解"，并取得 lock 变化全貌
- 试验副本 composer.json 相对仓库的 5 处改动：
  1. require.php: ">=5.6.0" -> ">=7.4 <8.5"
  2. require-dev.codeception/codeception: "^4.0" -> "^5.0"
  3. require-dev.codeception/module-yii2: "^1.0.0" -> "^1.1.12"（注意：不存在 1.3.x，v1.1 后直接跳 v2.0）
  4. require-dev.codeception/module-filesystem: "^1.0.0" -> "^3.0"
  5. require-dev.codeception/module-asserts: "^1.0.0" -> "^3.0"
     并移除 require-dev.symfony/browser-kit（其仍由 lib-innerbrowser 传递引入）
- config.platform.php = 8.4.0（模拟目标平台）
- 命令：composer update --dry-run --no-scripts --no-interaction
- 结果：求解成功，122 个包锁定；最低 PHP 要求 = 8.4（见 06）
