# 02 · 单点更新 `symfony/service-contracts` 的求解结果（失败）

- 环境：Composer 2.5.8 / 本地 CLI PHP 8.0.2
- 副本额外设置：`composer config platform.php 8.4.0`（仅模拟 8.4 目标平台，仓库内源文件未改）
- 命令：`composer update symfony/service-contracts --with-dependencies --dry-run`
- 退出码：2（不可解析）
- **结论：在其余 3 个阻塞项仍处于锁定状态时，单点更新无法求解。** Composer 拒绝产出对当前平台不合法的 lock，
  因此"`composer update symfony/service-contracts` 即可单点解除"这一说法**不能作为已完成事实**，只能作为
  "其余 3 项解除后、该包可由重新求解自动升到 3.x"的推论（该推论已由 `03-probe-console-service-contracts.txt` 验证）。
