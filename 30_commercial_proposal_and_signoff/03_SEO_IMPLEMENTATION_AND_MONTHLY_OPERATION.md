## B. 指标定义与统计口径

### B.1 指标定义

| 指标 | 口径 | 数据来源 | 承诺属性 |
|---|---|---|---|
| 网站访问量 | 全站会话/用户；区分总访问与自然搜索访问 | GA4 | 业务观察 |
| 自然搜索访问 | 非付费搜索来源的会话/用户 | GA4 + GSC | 业务观察 |
| 商品详情页访问（PDP views） | PDP 浏览量/访问用户 | GA4 | 业务观察 |
| 询价 CTA 点击（RFQ CTA clicks） | 点击询价按钮/加入 RFQ | GA4 事件 `rfq_click` | 业务观察 |
| 表单开始（form start） | 开始填写询价表单 | GA4 事件 `rfq_start` | 业务观察 |
| 表单提交（form submit） | 表单成功提交（含待审核） | 询盘系统 + `rfq_submit_success` | 业务观察 |
| 有效采购询盘量 | 经业务审核确认的有效询盘 | 询盘系统 + 审核 | 验收口径，非结果承诺 |
| 有效询盘率 | 有效询盘 ÷ 提交量 | 计算 | 业务观察 |
| 报价量 | 已向客户发出报价 | CRM/询盘系统 | 业务观察 |
| 成交量 | 已成交订单数量与金额 | 订单/CRM | 业务观察 |

### B.2 GSC 指标口径

- **曝光（Impressions）**：页面在搜索结果中被展示的次数，按查询/页面/国家/设备维度导出；
- **点击（Clicks）**：用户从搜索结果点击进入站点的次数；
- **平均排名（Average position）**：仅作趋势参考，不承诺具体名次；
- 数据延迟与抽样以 GSC 实际导出为准，报告中注明导出日期与区间。

### B.3 GA4 指标口径

- 自然搜索会话：`session_default_channel_group = Organic Search`；
- PDP 访问：商品详情页模板的 `page_view` 与 `view_item`；
- 事件以 GTM/GA4 配置为准，事件名与参数固定，变更走版本记录。

### B.4 有效采购询盘

有效采购询盘：具备可联系采购方信息、明确型号或真实采购需求，并经业务审核确认。

不计入：垃圾、测试、重复、明显无采购意图的提交。

询盘状态：**新询盘 → 待审核 → 有效询盘 → 已分配 → 已报价 → 已成交 / 已关闭**。

### B.5 去重与清洗

| 类型 | 处理 | 标记方式 |
|---|---|---|
| 重复提交 | 同一采购方/同一需求在窗口内重复 | `duplicate=true`，不计有效 |
| 机器人/自动提交 | 行为或来源异常 | `bot_suspected=true`，人工复核 |
| 内部测试 | 公司内部或实施方测试 | `internal_test=true`，排除 |
| 垃圾/无采购意图 | 内容明显无关 | `spam=true`，不计有效 |
| 跨渠道 | 首次/末次来源不同 | 分别保留 `first_source` / `last_source`，不重复计数 |

原始提交量与有效询盘量**分列报告**，不得混用。

### B.6 归因字段

`page_view`、`view_item`、`rfq_click`、`rfq_start`、`rfq_submit_success`、`contact_click`、`first_source`/`last_source`、`landing_page`、`mpn`、`country`。

与询盘系统字段对齐，字段缺失时标注 `PENDING`，不得默认填充。

### F.1 工作环节

| 环节 | 要求 | 交付/验收 |

> **表头口径**：「工作性质（服务类型）」是权威文件的工作性质分类，**不等于**六类费用状态；六类费用类别与报价状态以 `04 / 176_COST_STATUS`、`05` 各分区为准。15 项新增交付在本表中只列当前商务状态，均未进入已包含范围。

同一工作不在一次性开发费与持续运营费中重复计取。新增页面若超出运营包数量，按「单独报价」处理，需另行确认。

FR-3-040（外链与公关）虽纳入 119 项功能，但权威费用归属仅为「待负责人确认（建议：持续运营费）」；确认前不计入一次性开发费或持续运营费金额，确认后只归入其中一类，避免重复计费。

## H. 上线后监测与整改

对应交付：**OPS-02**。

### H.1 监测项

| 监测项 | 频率 | 异常处理 |
|---|---|---|
| 可用性/状态码 | 持续/每日 | 告警、定位、恢复 |
| 关键页面/抓取 | 每日/每周 | 清单核验、GSC/日志 |
| 索引/Sitemap | 每周/每月 | 异常分析、抓取错误 |
| 301/Canonical | 上线 4 周/每月 | 链式/循环/目标错误 |
| 结构化数据 | 每月 | Rich Results 错误 |
| 商品数据/询盘失败/归因 | 每周/每日 | 一致性、回执、字段异常 |
| 垃圾询盘异常增长 | 每周 | 规则与人工复核 |
| 搜索表现 | 每月 | GSC 趋势与异常清单 |

### H.2 问题分级（建议值，非最终 SLA）

| 等级 | 定义 | 建议响应 | 修复目标 |
|---|---|---|---|
| P0 | 站点不可用、数据泄露、询盘链路中断 | 立即 | 尽快恢复并复盘 |
| P1 | 核心流程不可用 | 4 小时内 | 当日给出方案 |
| P2 | 重要功能异常但有替代路径 | 1 个工作日 | 约定窗口内修复 |
| P3 | 一般问题/文案/样式/优化 | 3 个工作日 | 纳入月度批次 |

最终响应时限、保修期与赔偿以合同为准。

### H.3 问题记录字段

问题 ID、发现时间、严重级别、影响范围、责任方、响应时间、修复方案、完成时间、复测证据、关闭人。

### H.4 责任划分

| 情形 | 责任 | 处理 |
|---|---|---|
| 乙方开发缺陷 | 乙方 | 保修期内修复 |
| 乙方实施错误 | 乙方 | 定位、纠正、复核 |
| 第三方服务故障 | 供应商/第三方 | 乙方协助定位；供应商按条款 |
| 客户数据/客户修改 | 甲方 | 按合同约定 |
| 超范围需求 | 双方 | 变更评估 |
| 算法变化 | 双方 | 监测、分析、建议；不承诺恢复排名 |

### H.5 整改闭环

问题登记 → 定级 → 分派 → 修复 → 复测 → 证据归档 → 关闭。未复测通过不得关闭；连续未关闭项进入月度报告与升级机制。

## 附录：SEO 验收标准

验收对象是**工作、交付物和质量**，不是排名或询盘结果。

| 验收对象 | 标准 | 证据 |
|---|---|---|
| 页面清单 | 页面编号、URL、关键词、CTA、追踪、状态齐全 | 清单与发布记录 |
| 关键词台账 | 类型、意图、来源、状态、目标页齐全 | 台账导出 |
| 页面 SEO | Title/Description/Canonical/Robots/H1/Schema 符合规范 | 抓取/校验报告 |
| 迁移 | 映射台账、301/404/410 规则、全量盘点/关键 URL/分层抽样 | 回归报告 |
| 追踪 | 事件字典、字段、抽样日志 | 事件核对记录 |
| 月度运营 | 计划、工作记录、月报、整改闭环 | 月报与整改单 |

搜索排名、自然流量、询盘数量可作为业务观察指标；不作为固定结果验收或付款条件，除非双方另行书面约定。
