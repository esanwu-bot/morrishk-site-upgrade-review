# 未决事项（OD-01 ~ OD-21）

| 级别 | 含义 |
|---|---|
| **P0** | 阻断 Stage A / Stage B 启动；不裁定不得进入实现 |
| **P1** | 阻断 Stage C；可在 Stage B 期间裁定 |
| **P2** | 不阻断，但影响成本、可维护性或长期合规 |

决策人缩写：**R** = Reviewer；**A** = 甲方（Morrishk）；**B** = 乙方（贤戈网络）；**R+A** = 共同确认。

### OD-06 ID 与指纹的归一化

| 项 | 内容 |
|---|---|
| 问题 | `document_id` 只取 SHA 前 12 位（碰撞概率非零）；源码行尾 CRLF/LF 会让 `parser_fingerprint` 跨平台不同；`task_id` 是否继续用短哈希 |
| 影响 | 对象键与索引若用短 ID 可能冲突；Windows/Linux 指纹不可比；任务状态可能混淆 |

| 建议 | **A + C**，不改变既有 `document_id` 语义；`task_id` 已在 v1.1 改为完整 SHA-256（R5），此项部分关闭 |
| 决策人 | R |
| 触发 | Stage A 实现前 |
| 状态 | `task_id` 已解决；`document_id`/指纹归一化仍待确认 |
