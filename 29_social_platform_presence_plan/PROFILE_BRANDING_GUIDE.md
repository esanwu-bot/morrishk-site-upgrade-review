## 5. 链接与 UTM 规范

### 5.1 原则

1. 所有站外链接带 UTM；不裸链。
2. 落地页优先产品详情页，其次询盘页；**不落首页**（增长规划 §5.1）。
3. `utm_source` 用平台固定值；`utm_medium` 区分 social/video/community；`utm_campaign` 用月份或型号；`utm_content` 用帖子/视频标识。
4. 全部小写、无空格；型号统一小写，避免同一型号产生多种统计。

### 5.2 参数表

| 参数 | 取值 | 示例 |
|---|---|---|
| `utm_source` | `linkedin` / `youtube` / `facebook` / `instagram` / `x` / `pinterest` / `tiktok` / `reddit` / `medium` / `vimeo` | `linkedin` |
| `utm_medium` | `social` / `video` / `community` / `referral` | `social` |
| `utm_campaign` | `month2_launch` / `product_<mpn>` / `category_<slug>` | `product_m4t28` |
| `utm_content` | 帖子 ID / 视频 ID / 序列号 | `post_001` |

### 5.3 示例（占位型号，执行时替换为真实 URL）

```text
https://www.morrishk.net/{{lang}}/product/{{mpn}}?utm_source=linkedin&utm_medium=social&utm_campaign=product_{{mpn}}&utm_content=post_001
https://www.morrishk.net/{{lang}}/inquiry?utm_source=youtube&utm_medium=video&utm_campaign=month2_launch&utm_content=video_001
```

> 不确认站点实际路由前，不生成真实链接；本包不修改站点路由或参数处理逻辑。

## 7. 禁用宣称与合规红线

| 禁止写法 | 原因 | 替代写法 |
|---|---|---|
| “leading / largest / No.1 supplier” | 无法证实，易构成误导 | “multilingual electronic components website” |
| “authorized distributor / official partner” | 需授权证据 | 仅在有书面授权时使用 |
| “ISO certified / UL / RoHS compliant” | 需证书与适用范围 | 用户提供证书后再写，注明范围 |
| “in stock / same-day shipping / global warehouse” | 需实时库存与履约证据 | “contact us for availability” |
| “guaranteed lowest price” | 价格承诺风险 | “send an inquiry for a quote” |
| 客户 logo / 案例 | 需客户授权 | 未授权不使用 |
| 虚假地址/电话 | 平台与法律风险 | 用户确认后填 |
| 在 Reddit 发纯推广链接 | 违反社区规则（E-34） | 只做有数据出处的技术答疑 |
