# SEO 第二个月执行计划

> 目标不是“把账号都注册一遍”，而是用最小可运营矩阵，建立可被搜索、可被度量、可持续更新的品牌主页与视频资产。
> 本计划需用户授权后才执行；当前所有任务状态均为“待授权”。

## 1. 目标与验收口径

### 1.1 业务目标

1. 让品牌词与核心型号在 LinkedIn/YouTube/Facebook/Instagram/X 上有可检索的官方落点。
2. 让每条站外内容都能通过 UTM 回到产品详情页或询盘页。
3. 建立一套可复用的人机协作流程：人工审核 + 工具排程，不追求全自动。
4. 为第三个月的付费决策（认证/订阅/广告）提供真实数据。

### 1.2 本月验收（运营指标，不是业绩承诺）

| 指标 | 目标 | 说明 |
|---|---|---|
| 核心主页上线 | 5 个（LinkedIn、YouTube、Facebook、Instagram、X） | 资料完整、可公开访问 |
| 资料完整率 | 100% | 按各平台检查清单逐项打勾 |
| YouTube 视频 | ≥3 条（目标 4） | 含 1 条品牌/站点导览 |
| 图文内容 | ≥20 条（跨平台合计，含复用） | LinkedIn 8、IG 8、FB 8、X 12 为上限参考，实际按产能 |
| Reddit 技术答疑 | ≥2 次（人工、非推广） | 只在确有帮助时参与 |
| Postiz 连接 | 5 个核心平台（若采用） | 连接成功并可完成 1 次测试草稿 |
| 度量基线 | 100% 建立 | 每个平台记录起始数据与 UTM 会话/询盘 |
| 违规/返工 | 0 次平台警告 | 无 spam、无未证实宣称 |

> 不设“粉丝数/询盘数”硬指标：第二个月样本太小，强设目标会诱导刷量或夸大内容。

## 2. 执行原则

| 原则 | 说明 | 来源 |
|---|---|---|
| 人工优先 | 先人工建号、发首批内容，再谈自动化 | 增长规划 §5.1 |
| 合规优先 | 不绕过审核、不群发、不刷量、不买粉 | 增长规划 §5.2 |
| 一次编辑，多平台适配 | 同一素材按平台改写，不原样复制 | 增长规划 §5.2 |
| UTM 必须 | 所有站外链接落到产品详情/询盘，不落首页 | 增长规划 §5.1 |
| 不编造事实 | 认证、库存、交期、代理关系必须有证据 | 任务书 + 品牌规范 |
| 少而稳 | 宁可每周 1 条视频，不要爆发后断更 | 本计划 |

## 9. 明确不做

- 不买粉、不刷互动、不群发私信、不批量注册。
- 不在 Reddit 发纯推广链接或软文。
- 不发布未证实的认证、库存、交期、代理关系、客户案例。
- 不在第二个月投广告（广告另立预算与审批）。
- 不为了“全平台覆盖”而开设无内容、无维护的账号。
- 不把 Postiz 当“无人值守发布机”；发布前必须有人审。

## 10. 月度退出标准

满足以下全部条件，才算第二个月完成：

1. 5 个核心主页上线且资料完整率 100%。
2. YouTube ≥3 条视频，含频道预告片与至少 3 个可用播放列表。
3. 图文内容 ≥20 条（跨平台合计），全部带 UTM 或明确的落地页。
4. 所有账号 2FA + 双管理员；无凭证泄露。
5. 基线报表完成；每条内容可追溯到来源与落地页。
6. 无平台警告、无违规下架、无未证实宣称。
7. 复盘成文，第三个月计划与预算建议提交用户。
